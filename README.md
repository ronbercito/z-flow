# Z-FLOW

Sistema para gestionar operaciones de Yape y efectivo, cajas, cierres y comisiones por filial.

## Funciones

- Administración de filiales y encargados.
- Registro de operaciones y control de saldos.
- Apertura y cierre de caja con conciliación.
- Reportes, comprobantes internos y auditoría.
- Copias de seguridad y restauración.

## Tecnología

React · Fastify · TypeScript · MariaDB · Docker Compose
